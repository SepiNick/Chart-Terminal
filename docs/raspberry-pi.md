# سرور شخصی روی رزبری پای + ربات تلگرام

سرور خصوصی (همان `docker-compose.yml`) روی پای اجرا می‌شود و فقط از شبکه‌ی خانه در دسترس است. هشدارها، ضبط معامله‌ها و ربات تلگرام همیشه روشن می‌مانند، حتی وقتی کامپیوتر خاموش است.

## ۱. نصب روی پای

پیش‌نیاز: پای با Raspberry Pi OS (۶۴ بیتی)، متصل به شبکه‌ی خانه و SSH روشن (`sudo raspi-config` → Interface Options → SSH). بهتر است در مودم برای پای IP ثابت (DHCP reservation) بگذارید.

از پوشه‌ی پروژه روی کامپیوتر (Git Bash یا WSL):

```bash
scripts/deploy-pi.sh pi@192.168.1.50
```

(آدرس را با آدرس پای عوض کنید.) اسکریپت سورس را کپی می‌کند، Docker را در صورت نبودن نصب می‌کند و سرور را می‌سازد و بالا می‌آورد. ساخت اول روی پای چند دقیقه طول می‌کشد. برای به‌روزرسانی همین دستور را دوباره بزنید؛ داده‌ها (volume) می‌مانند.

رمز اول فقط از خود پای گذاشته می‌شود (سرور از شبکه این کار را رد می‌کند). دستور زیر رمز را از شما می‌پرسد (حداقل ۸ نویسه) و روی خود پای ثبت می‌کند:

```bash
ssh -t pi@192.168.1.50 'read -rsp "New password: " p; echo; curl -s -X POST http://127.0.0.1:8787/api/auth/setup -H "content-type: application/json" -d "{\"password\":\"$p\"}"'
```

جواب `{"ok":true}` یعنی رمز ثبت شد.

## ۲. اضافه کردن سرور به برنامه‌ها

آدرس سرور روی شبکه‌ی خانه: `https://<IP پای>:8443`. گواهی را یک بار نصب کنید تا مرورگر و WebView هشدار ندهند: `https://<IP پای>:8443/ca.crt` (آیفون: `/ca.mobileconfig`)؛ جزئیات در [lan-setup.md](lan-setup.md) و [android-apk.md](android-apk.md).

- **اندروید:** APK نسخه‌ی *client* را نصب کنید و در صفحه‌ی اول آدرس را بزنید. (نسخه‌ی standalone سرور ندارد؛ برای سرور باید *client* باشد.)
- **ویندوز (برنامه‌ی دسکتاپ):** در نوار پایین برنامه‌ی standalone روی «Connect to a server» بزنید و آدرس را بدهید؛ ورود با رمزی که ساختید.
- **مرورگر / آیفون:** مستقیم آدرس را باز کنید و «Add to Home Screen» بزنید.

## ۳. ربات تلگرام

ربات برای دو کار است: اعلان هشدارها و **ورود با حساب تلگرام**.

1. در تلگرام با @BotFather یک ربات بسازید (`/newbot`) و توکن را نگه دارید.
2. در برنامه (وصل به سرور پای): «Server & notifications» ← بخش Telegram ← توکن را بچسبانید و Save بزنید.
3. در تلگرام به رباتتان یک پیام بدهید، سپس در همان بخش «Pick chat» را بزنید و گفتگوی شخصی خودتان را انتخاب کنید.
4. «Send test» را بزنید؛ باید پیام تست برسد.

**ورود با تلگرام:** بعد از این مراحل، در صفحه‌ی ورود دکمه‌ی «Sign in with Telegram» ظاهر می‌شود: لینک `t.me` باز می‌شود، Start را بزنید و فقط اگر ربات همان کد ۴ رقمی صفحه را نشان داد Approve را بزنید. فقط همان حساب تلگرامی که گفتگوی اعلان‌هاست می‌تواند وارد شود. به دامنه و HTTPS عمومی نیازی ندارد.

> **اینترنت پای:** پای باید به `api.telegram.org` و برای داده‌ی Binance به `binance.com` دسترسی داشته باشد. در ایران معمولاً این‌ها بدون VPN باز نیستند؛ پس روی پای هم VPN یا پروکسی لازم است (مثلاً کلاینت VPN روی خود پای یا روی مودم). بدون آن، ربات و داده‌ی زنده کار نمی‌کنند.

## ۴. ورود رسمی تلگرام (Telegram Login)

دکمه‌ی رسمی تلگرام به یک **دامنه‌ی واقعی با HTTPS معتبر** نیاز دارد که در BotFather (`/setdomain`) ثبت شود؛ روی آدرس IP شبکه‌ی خانه کار نمی‌کند. این بخش هنوز در برنامه پیاده نشده و فقط وقتی دامنه دارید (سرور عمومی، [docker.md](docker.md)) معنا دارد.

## نگهداری

```bash
ssh pi@192.168.1.50 'cd ~/chart-terminal && sudo docker compose logs -f app'      # لاگ
ssh pi@192.168.1.50 'cd ~/chart-terminal && sudo docker compose restart app'      # راه‌اندازی دوباره
```

پشتیبان داده: دستور `docker run --rm -v chart-terminal-data:/d ...` در [docker.md](docker.md).
