# گزارش باگ داخل برنامه

منوی ☰ ← «Report a bug…». کاربر توضیح می‌نویسد، تا ۳ عکس (اختیاری) می‌گذارد و راه تماس (اختیاری) می‌دهد. اطلاعات تشخیصی خودکار همراه است (نسخه، سیستم‌عامل، اندازه‌ی صفحه، نمادها و تنظیمات نمودار، خطاهای اخیر برنامه) و با تیک می‌شود حذفش کرد. کلید، رمز، توکن، ایمیل و IP در آن نیست (`src/diagnostics.ts`). عکس‌ها قبل از ارسال به حداکثر ۱۶۰۰ پیکسل و JPEG کوچک می‌شوند.

## گزارش به کجا می‌رود

1. **برنامه به سرور وصل است** (مثلاً سرور رزبری پای): `POST /api/bugreport`؛ گزارش و عکس‌ها در `<داده‌ی سرور>/bugreports/<شناسه>/` ذخیره می‌شوند و اگر ربات تلگرام و گفتگوی شخصی در «Server & notifications» تنظیم شده باشد، متن، فایل تشخیصی و عکس‌ها به همان گفتگو می‌روند (`server/bugreport.ts`).
2. **سرور وصل نیست و آدرس گزارش داخل برنامه ساخته شده:** با ساخت برنامه `VITE_BUG_REPORT_URL=https://…` را بگذارید؛ برنامه همان JSON را (`{ description, contact, info, images[] }`، عکس‌ها data URL) با `POST` به آن آدرس می‌فرستد. آدرس باید https باشد.
3. **هیچ‌کدام:** گزارش به‌صورت یک فایل `.json` ذخیره می‌شود و کاربر خودش برای شما می‌فرستد.

نسخه‌ی standalone (بدون سرور) فقط با حالت ۲ یا ۳ کار می‌کند. گیرنده‌ی عمومی (سرور یا ایمیل اختصاصی) هنوز تنظیم نشده است.
