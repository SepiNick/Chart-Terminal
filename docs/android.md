# استفاده در اندروید (نصب به‌صورت اپ)

در این روش گوشی فقط «نمایشگر» است و همه‌چیز (سرور، اعلان‌ها، داده‌ها) روی یک کامپیوتر همیشه‌روشن در خانه اجرا می‌شود: لپ‌تاپ لینوکسی (راهنما: [headless-server.md](headless-server.md)) یا همان PC ویندوزی ([lan-setup.md](lan-setup.md)). اپ با Chrome به‌صورت PWA نصب می‌شود و Chrome برایش یک WebAPK واقعی می‌سازد: آیکون روی صفحه‌ی اصلی، بدون نوار آدرس، با اعلان‌های خودش.

## پیش‌نیازها

- سرور روی لپ‌تاپ اجرا شده و Home network access روشن است (`CT_LAN=1`). در لاگ سرور نشانی‌هایی مثل `https://192.168.1.20:8443` و یک QR می‌بینید.
- **اولین رمز عبور را باید روی خود لپ‌تاپ بگذارید** (نه از گوشی). مرورگر لپ‌تاپ را روی `http://127.0.0.1:8787` باز کنید، یا از راه دور: `ssh -L 8787:127.0.0.1:8787 user@laptop` و بعد `http://127.0.0.1:8787` را روی کامپیوتر خودتان باز کنید. تا رمز تنظیم نشود، ورود از شبکه رد می‌شود.
- `npm run build` زده شده باشد (سرور پوشه‌ی `dist/` را سرو می‌کند).
- گوشی و لپ‌تاپ روی **یک Wi-Fi** باشند و VPN گوشی خاموش باشد (یا گزینه‌ی دسترسی به شبکه‌ی محلی داشته باشد)؛ VPN معمولاً دسترسی به شبکه‌ی محلی را می‌بندد.

## مرحله ۱: نصب گواهی (فقط یک بار)

1. در Chrome گوشی `https://<IP>:8443/ca.crt` را باز کنید. Chrome هشدار امنیتی می‌دهد؛ طبیعی است. **Advanced → Proceed** را بزنید تا فایل `chart-terminal-ca.crt` دانلود شود.
2. **Settings → Security & privacy → More security settings → Encryption & credentials → Install a certificate → CA certificate** → **Install anyway** → فایل دانلودشده را انتخاب کنید. (نام منو در گوشی‌های مختلف فرق می‌کند؛ «CA certificate» را در Settings جست‌وجو کنید. گوشی باید قفل صفحه داشته باشد.)
3. Chrome را از لیست برنامه‌های اخیر کامل ببندید و دوباره باز کنید.
4. `https://<IP>:8443` را باز کنید. باید بدون هشدار و با قفل سالم باز شود. برای اطمینان، اثر انگشت SHA-256 گواهی (در تنظیمات اپ روی لپ‌تاپ) را با جزئیات گواهی نصب‌شده مقایسه کنید.

## مرحله ۲: نصب به‌عنوان اپ

1. وارد شوید (رمزی که روی لپ‌تاپ گذاشتید).
2. منوی ⋮ در Chrome → **Install app** (یا **Add to Home screen → Install**). اگر فقط «Add shortcut» دیدید، یعنی Chrome هنوز گواهی را معتبر نمی‌داند: مرحله‌ی ۱ را دوباره بررسی کنید.
3. اپ را **از آیکون روی صفحه‌ی اصلی** باز کنید. باید تمام‌صفحه و بدون نوار آدرس باز شود.

مهم: اپ به **نشانی دقیق** (`https://192.168.1.20:8443`) وصل است. اگر IP عوض شود، اپ نصب‌شده دیگر باز نمی‌شود و باید دوباره نصب شود. پس مرحله‌ی «IP ثابت» پایین را حتماً انجام دهید.

## مرحله ۳: اعلان‌ها (Push)

1. در اپ نصب‌شده: تنظیمات → Server & notifications → اعلان‌ها را برای این دستگاه روشن کنید → **Allow**.
2. یک هشدار تست بسازید و ببینید اعلان می‌رسد.
3. اعلان‌ها از سرویس Google (FCM) عبور می‌کنند، پس هم گوشی و هم لپ‌تاپ باید **اینترنت** داشته باشند؛ فقط Wi-Fi محلی کافی نیست.
4. اگر اعلان نیامد: Settings گوشی → Apps → Chart Terminal → Notifications روشن باشد.

## تنظیمات باتری (برای رسیدن اعلان در پس‌زمینه)

- Settings → Apps → **Chart Terminal** (بعضی گوشی‌ها فقط «Chrome» را نشان می‌دهند) → Battery → **Unrestricted** (یا «Don't optimize»).
- همین کار را برای **Chrome** هم بکنید.
- Samsung: Battery → Background usage limits → Never sleeping apps → اضافه کردن. Xiaomi/Huawei/Oppo: Autostart را هم روشن کنید و اپ را در Recent قفل کنید.
- Data Saver را برای این اپ خاموش کنید.

## وقتی IP لپ‌تاپ عوض می‌شود

1. **بهترین راه: DHCP reservation.** در پنل مودم (معمولاً `192.168.1.1`) بخش LAN → DHCP → Static lease / Address reservation، MAC لپ‌تاپ را به یک IP ثابت (مثلاً `192.168.1.20`) ببندید. در لینوکس MAC را با `ip -br link` ببینید. بعد از آن نشانی اپ هرگز عوض نمی‌شود.
2. اگر IP عوض شد: سرور خودش ظرف حدود یک دقیقه گواهی را با همان CA دوباره می‌سازد (CA را دوباره نصب نکنید)، ولی اپ نصب‌شده به نشانی قدیمی وصل است: آن را پاک کنید، با نشانی جدید در Chrome باز کنید و دوباره Install app بزنید.
3. **نام mDNS (آزمایشی):** سرور نام `<hostname>.local` را هم در گواهی می‌گذارد و می‌پذیرد (روی لپ‌تاپ `avahi-daemon` باید فعال باشد). در اندروید حل‌شدن نام `.local` روی همه‌ی نسخه‌ها و گوشی‌ها قابل اتکا نیست؛ `https://<hostname>.local:8443` را امتحان کنید و اگر باز نشد به IP ثابت برگردید. اگر کار کرد، اپ را با همین نام نصب کنید تا به IP وابسته نباشد.

## اشکال‌یابی سریع

| مشکل | علت و راه‌حل |
|---|---|
| صفحه باز نمی‌شود | فایروال لپ‌تاپ، Wi-Fi متفاوت، یا VPN گوشی. ابتدا `https://<IP>:8443/ca.crt` را امتحان کنید. |
| هشدار گواهی بعد از نصب | Chrome را کامل ببندید؛ گواهی باید «CA certificate» باشد نه «VPN & app user certificate». |
| ورود رد می‌شود (۴۰۳) | هنوز رمز اول روی لپ‌تاپ تنظیم نشده. |
| Install app نیست | Chrome را به‌روز کنید؛ باید با نشانی HTTPS مورد اعتماد باز شده باشد. |
