# دسترسی از گوشی روی شبکه‌ی خانه (HTTPS، اعلان‌ها و نصب اپ)

با این راهنما می‌توانید Chart Terminal را روی گوشی (اندروید یا آیفون) از طریق Wi-Fi خانه باز کنید، اعلان‌های Push بگیرید و آن را مثل یک اپ روی صفحه‌ی اصلی نصب کنید.

چرا HTTPS؟ مرورگرها اعلان Push و Service Worker را فقط روی اتصال امن فعال می‌کنند. برای همین سرور یک «مرجع صدور گواهی محلی» (Local CA) مخصوص همین کامپیوتر می‌سازد. کافی است این گواهی را یک بار روی گوشی نصب کنید تا گوشی به سرور اعتماد کند. این گواهی فقط روی کامپیوتر شما ساخته می‌شود و جای دیگری فرستاده نمی‌شود.

## ۱. روشن کردن دسترسی از شبکه‌ی خانه

1. سرور را اجرا کنید (`npm run server`) و برنامه را روی **همین کامپیوتر** باز کنید.
2. در تنظیمات «Server & notifications» بخش **Home network access** را روشن کنید. این کار فقط از خود این کامپیوتر ممکن است.
3. نشانی‌هایی مثل `https://192.168.1.20:8443` نمایش داده می‌شوند. همین نشانی را روی گوشی باز خواهید کرد.

برای اینکه گوشی برنامه‌ی ساخته‌شده را ببیند، یک بار `npm run build` بزنید (سرور پوشه‌ی `dist/` را سرو می‌کند).

اگر نشانی IP کامپیوتر عوض شود (مثلاً مودم IP جدید بدهد)، سرور خودش گواهی را دوباره می‌سازد. CA عوض نمی‌شود، پس لازم نیست گواهی را دوباره روی گوشی نصب کنید. بهتر است در تنظیمات مودم برای این کامپیوتر یک IP ثابت (DHCP reservation) بگذارید تا نشانی همیشه یکی بماند.

> **بدون مرورگر / اندروید:** سرور را با `CT_LAN=1` (یا `node index.ts --lan`) اجرا کنید تا دسترسی شبکه بدون UI روشن شود (رمز اول همچنان فقط از خود کامپیوتر). برای لپ‌تاپ لینوکسی همیشه‌روشن: [headless-server.md](headless-server.md). مراحل کامل گوشی اندرویدی و نصب به‌صورت اپ: [android.md](android.md).

## ۲. باز کردن پورت در فایروال ویندوز

PowerShell را **به‌عنوان Administrator** باز کنید و این دستور را بزنید. قانون فقط برای شبکه‌های Private (شبکه‌ی خانه) است، نه شبکه‌های عمومی:

```powershell
New-NetFirewallRule -DisplayName "Chart Terminal HTTPS (LAN)" -Direction Inbound -Protocol TCP -LocalPort 8443 -Action Allow -Profile Private
```

مطمئن شوید شبکه‌ی Wi-Fi خانه در ویندوز روی **Private** تنظیم شده است (Settings → Network & internet → Wi-Fi → نام شبکه → Network profile type → Private).

برای حذف قانون در آینده:

```powershell
Remove-NetFirewallRule -DisplayName "Chart Terminal HTTPS (LAN)"
```

## ۳. اندروید

1. گوشی را به همان Wi-Fi وصل کنید و در Chrome نشانی `https://<IP>:8443/ca.crt` را باز کنید تا فایل گواهی دانلود شود. (اگر Chrome هشدار امنیتی داد، چون هنوز گواهی نصب نشده طبیعی است؛ گزینه‌ی Advanced و ادامه را بزنید.)
2. بروید به **Settings → Security → Encryption & credentials → Install a certificate → CA certificate**، هشدار را تأیید کنید و فایل `chart-terminal-ca.crt` را انتخاب کنید. نام منوها در گوشی‌های مختلف کمی فرق دارد؛ در صورت نیاز در Settings عبارت «CA certificate» را جست‌وجو کنید.
3. Chrome را کامل ببندید و دوباره `https://<IP>:8443` را باز کنید. حالا باید قفل سالم نشان داده شود.
4. وارد شوید و در تنظیمات، اعلان‌ها (Push) را برای این دستگاه روشن کنید و وقتی Chrome اجازه خواست، **Allow** را بزنید.
5. (اختیاری) از منوی ⋮ گزینه‌ی **Add to Home screen** یا **Install app** را بزنید تا برنامه مثل یک اپ جدا باز شود.

## ۴. آیفون (iOS 16.4 یا جدیدتر)

1. گوشی را به همان Wi-Fi وصل کنید و در **Safari** نشانی `https://<IP>:8443/ca.mobileconfig` را باز کنید و دانلود پروفایل را تأیید کنید.
2. به **Settings** بروید؛ بالای صفحه «Profile Downloaded» دیده می‌شود. آن را باز کنید و **Install** را بزنید (رمز گوشی را می‌خواهد).
3. حالا اعتماد کامل را روشن کنید: **Settings → General → About → Certificate Trust Settings** و کلید کنار «Chart Terminal Local CA» را روشن کنید. بدون این مرحله Safari به سرور اعتماد نمی‌کند.
4. در Safari نشانی `https://<IP>:8443` را باز کنید و وارد شوید.
5. دکمه‌ی **Share** را بزنید و **Add to Home Screen** را انتخاب کنید.
6. برنامه را **از آیکون روی صفحه‌ی اصلی** باز کنید (نه از Safari)، دوباره وارد شوید، در تنظیمات اعلان‌ها را روشن کنید و وقتی پرسید **Allow** را بزنید.

نکته‌ی مهم: در آیفون اعلان Push فقط از اپی کار می‌کند که روی صفحه‌ی اصلی نصب شده است. در تب معمولی Safari گزینه‌ی اعلان در دسترس نیست.

## اشکال‌یابی

- **گوشی صفحه را باز نمی‌کند:** مطمئن شوید هر دو دستگاه روی یک Wi-Fi هستند، قانون فایروال اضافه شده و شبکه روی Private است. VPN روی گوشی ممکن است دسترسی به شبکه‌ی محلی را ببندد؛ اگر صفحه باز نشد، یک بار VPN گوشی را خاموش کنید یا گزینه‌ی «Allow LAN» آن را روشن کنید.
- **خطای گواهی بعد از نصب:** در اندروید Chrome را کامل ببندید؛ در آیفون مرحله‌ی Certificate Trust Settings را دوباره بررسی کنید. اگر پوشه‌ی `server/data/tls` را پاک کرده باشید، CA تازه ساخته شده و باید دوباره نصب شود.
- **openssl پیدا نشد:** سرور openssl را به این ترتیب جست‌وجو می‌کند: متغیر محیطی `CT_OPENSSL`، سپس PATH، سپس نسخه‌ای که همراه Git for Windows نصب می‌شود. اگر هیچ‌کدام نبود، Git for Windows را نصب کنید یا مسیر کامل `openssl.exe` را در `CT_OPENSSL` بگذارید.
- **اثر انگشت گواهی:** در تنظیمات، اثر انگشت SHA-256 گواهی CA نمایش داده می‌شود. اگر خواستید مطمئن شوید گواهی درست را نصب کرده‌اید، آن را با جزئیات گواهی روی گوشی مقایسه کنید.
