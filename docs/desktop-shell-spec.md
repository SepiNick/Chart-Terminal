# مشخصات رفتاری پوسته‌ی دسکتاپ TradingView 3.4.1

> **روش clean-room:** این سند فقط *رفتار* را توصیف می‌کند. هیچ کدی از TradingView در آن یا در پروژه کپی نشده است.
> منبع: نسخه‌ی نصب‌شده روی همین سیستم (`TradingView.Desktop_3.4.1.8194`)، شامل فهرست فایل‌های `app.asar`، فایل‌های `configs/*.json`، نام کانال‌های IPC در `preload/*.js`، و ۳۶۷ متن رابط کاربری در `resources/locales/en.json`.
> شناسه‌ی مدرک REA مربوط به `app.asar`: `ev_3ed35508f7d7d60b30650a272eb11f3b762d67368e2af424731b51caf7151c4e`

## ۱. معماری

| بخش | مشاهده‌شده | معادل در پروژه‌ی ما |
|---|---|---|
| فرایند اصلی | `index.js`؛ پنجره‌ها و تب‌ها را مدیریت می‌کند و سایت `www.tradingview.com/chart/` را در هر تب بارگذاری می‌کند | فاز ۷: Electron که `index.html` خود ما را بارگذاری کند |

| پل مرورگر و برنامه | ۵ فایل preload که به سایت API ویژه‌ی دسکتاپ می‌دهند (جدول بخش ۳) | یک preload با `contextBridge` |

| گزارش خطا | Sentry و Google Analytics | لازم نیست |

## ۲. قابلیت‌های پوسته (از متن‌های رابط کاربری)

- **تب‌ها:** تکثیر، جدا کردن به پنجره‌ی جدید، بستن تب‌های دیگر یا سمت راست، تغییر عنوان، گروه تب، و مخفی کردن تب‌ها در حالت تمام‌صفحه.
- **همگام‌سازی بین تب‌ها با برچسب رنگی:** نماد، تایم‌فریم، زمان (date range) و crosshair. تب‌هایی که برچسب رنگی یکسان دارند با هم هماهنگ می‌شوند، حتی در چند مانیتور.
- **چیدمان‌ها (layouts):** ساختن، تغییر نام، کپی، حذف (با نمایش تعداد رسم‌ها)، مرتب‌سازی بر اساس نام یا تاریخ، سقف تعداد بسته به نوع اشتراک، و بازگرداندن خودکار نماد و تایم‌فریم.
- **تنظیمات برنامه:** تم (تیره، روشن یا هماهنگ با سیستم)، غیرفعال کردن شتاب سخت‌افزاری، پاک کردن cache، Factory reset، پوشه‌ی دانلود، پر کردن خودکار رمز بروکر، و دسترسی به میکروفون، دوربین و ضبط صفحه.
- **منوی شروع (new-tab):** Heatmap (کریپتو و ETF)، تقویم‌ها (اقتصادی، سود سهام، گزارش مالی، IPO)، Fundamental Graphs، ایده‌های Community، جفت‌ارزهای CEX و DEX، و دسته‌های بازار (اوراق، ETF، کریپتو).
- **ورود به حساب:** از طریق مرورگر، کد دومرحله‌ای، و چسباندن کلید مخفی.
- **به‌روزرسانی خودکار**، صفحه‌ی خطا و صفحه‌ی crash.
- **۴۵ صدای هشدار** در ۵ دسته: عمومی، funny، nature، soft و voices.

## ۳. کانال‌های IPC (رابط بین سایت و برنامه)

| کانال | کاری که از نامش برمی‌آید (استنباط) |
|---|---|
| `tvd:get-credentials` / `tvd:set-credentials` | خواندن و ذخیره‌ی رمز بروکر در keytar |
| `tvd:get-watchlist` / `tvd:watchlist-change` | همگام‌سازی Watchlist بین تب‌ها |
| `tvd:get-crosshair-sync` / `tvd:crosshair-sync-setting-update` | همگام‌سازی crosshair |
| `tvd:update-link-values` | پخش نماد، تایم‌فریم و زمان بین تب‌های هم‌رنگ |
| `tvd:layout-change` / `tvd:layout-restored` | ذخیره و بازگرداندن چیدمان |
| `tvd:get-theme` / `tvd:set-theme-setting` / `tvd:update-theme` | تم |
| `tvd:set-notification` / `tvd:set-notification-viewed` | نوتیفیکیشن سیستمی (برای هشدارها) |
| `tvd:focus-pine-editor` | آوردن Pine Editor به جلو |
| `tvd:open-new-window` / `tvd:reload-tab` / `tvd:set-title` | مدیریت پنجره و تب |
| `tvd:get-audio` / `tvd:get-camera` / `tvd:get-screen` | دسترسی‌های رسانه‌ای |
| `tvd:native-input-string` | ورودی متنی بومی (کاربرد دقیق نامعلوم) |
| `tvd-main:initiate-sign-in` / `tvd-main:set-locale` | ورود به حساب و زبان |

ستون دوم از روی نام کانال‌ها استنباط شده و رفتار واقعی آن‌ها در حال اجرا مشاهده نشده است.

## ۴. چیزهایی که در این برنامه نیست (و باید از صفر ساخته شود)

موتور نمودار، ابزارهای رسم، اندیکاتورها، Pine Script (کامپایلر روی سرور)، Strategy Tester، Screener، Trading Panel و اتصال بروکرها. همه‌ی این‌ها از سایت TradingView بارگذاری می‌شوند. برای مشخص کردن رفتار آن‌ها، از روی رابط کاربری برنامه‌ی در حال اجرا مشاهده می‌کنیم (منوها، پنجره‌های تنظیمات، فهرست ابزارها) و رفتار را مستند می‌کنیم، نه کد را.
