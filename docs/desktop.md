# برنامه‌ی دسکتاپ Chart Terminal (ویندوز، مک، لینوکس)

برنامه‌ی دسکتاپ همان Chart Terminal است، با سرورِ خودش درون برنامه. نصب Node، اجرای جداگانه‌ی سرور یا مرورگر لازم نیست.

## چطور کار می‌کند
- **ساختار:** پوسته‌ی Electron (`desktop/main.cjs`) سرور را روی یک پورت آزاد از `127.0.0.1` اجرا می‌کند و برنامه را از همان سرور در یک پنجره نشان می‌دهد.
- **داده‌ها:** داده‌های برنامه (رمز، چیدمان‌ها، ژورنال، هشدارها و کلیدهای رمزنگاری‌شده) در پوشه‌ی داده‌ی کاربر ذخیره می‌شوند:
  - ویندوز: `%APPDATA%\Chart Terminal\data`
  - مک: `~/Library/Application Support/Chart Terminal/data`
  - لینوکس: `~/.config/Chart Terminal/data`
- **اولین اجرا:** برنامه با داده‌ی خالی شروع می‌شود و رمز اول را می‌پرسد. سرورِ جداگانه (`server/data`) دست نمی‌خورد.
- **بستن پنجره:** سرور هم بسته می‌شود. یعنی هشدارهای سمت سرور، forward testها و ضبط معاملات فقط وقتی برنامه باز است کار می‌کنند. برای کار شبانه‌روزی، سرور را روی VPS اجرا کنید.
- **Web Push:** در برنامه‌ی دسکتاپ کار نمی‌کند. popup و صدای هشدار کار می‌کند.
- **دو بار باز کردن:** اگر برنامه را دوباره باز کنید، همان پنجره‌ی قبلی جلو می‌آید.

## ساختن نصبی
پیش‌نیاز: Node.js نسخه‌ی ۲۲ یا بالاتر روی همان سیستم.

```bash
npm ci
```
```bash
cd desktop
```
```bash
npm ci
```
بعد، روی هر سیستم‌عامل دستور خودش را اجرا کنید:

| سیستم‌عامل | دستور | خروجی در `desktop/release/` |
|---|---|---|
| ویندوز | `npm run dist:win` | `Chart Terminal Setup <نسخه>.exe` |
| مک | `npm run dist:mac` | دو فایل `.dmg`: اینتل (x64) و Apple Silicon (arm64) |
| لینوکس | `npm run dist:linux` | `.AppImage` و `.deb` |

نصبی مک فقط روی خودِ مک ساخته می‌شود. نصبی لینوکس هم روی لینوکس ساخته شود.

برای امتحان بدون نصب: `npm start` در پوشه‌ی `desktop`. اگر npm اسکریپت نصب Electron را اجرا نکرده باشد، `npm start` برنامه را پیدا نمی‌کند. در این حالت یک بار `node node_modules/electron/install.js` را بزنید. دستورهای `dist:*` به این مورد نیازی ندارند.

## نصب بدون امضای دیجیتال
نصبی‌ها امضا نشده‌اند. سیستم‌عامل یک بار هشدار می‌دهد:

- **ویندوز (SmartScreen):** روی «More info» و بعد «Run anyway» بزنید.
- **مک:** برنامه را به Applications بکشید. بار اول روی آن راست‌کلیک کنید، «Open» را بزنید و دوباره «Open» را تأیید کنید. اگر پیام «damaged» آمد، در Terminal این را بزنید:
  ```bash
  xattr -dr com.apple.quarantine "/Applications/Chart Terminal.app"
  ```
  برنامه با امضای ad-hoc ساخته می‌شود، چون Apple Silicon برنامه‌ی کاملاً بدون امضا را اجرا نمی‌کند.
- **لینوکس:**
  - **deb (برای Ubuntu 24.04 پیشنهادی):** `sudo apt install ./<فایل>.deb`.
  - **AppImage:** اول `chmod +x <فایل>.AppImage` و بعد اجرا. روی Ubuntu جدید `libfuse2` لازم است (روی 24.04 اسمش `libfuse2t64` است). اگر AppArmor جلوی sandbox را گرفت، deb را نصب کنید یا AppImage را با `--no-sandbox` اجرا کنید.

## برای توسعه
- **`window.prompt()`:** Electron این تابع را ندارد. `desktop/preload.cjs` آن را با یک پنجره‌ی کوچک ورودی جایگزین می‌کند تا نام‌گذاری چیدمان، قالب و تایم‌فریم سفارشی کار کند.
- **پورت ثابت:** پورت انتخاب‌شده در `port.txt` ذخیره می‌شود و برنامه همیشه با همان آدرس باز می‌شود، پس تنظیمات محلی مرورگر هم حفظ می‌شوند.
- `desktop/build.mjs` دو کار می‌کند:
  - کلاینت را با Vite می‌سازد (`app/dist`).
  - سرور و worker موتور اسکریپت را با esbuild در یک فایل bundle می‌کند (`app/server`).
- پکیج‌های npm سرور (ccxt، ws، nodemailer، web-push) از `desktop/package.json` نصب می‌شوند.
- برای آزمایش بدون دست زدن به داده‌ی واقعی، پوشه‌ی داده را با `CT_USER_DATA=<پوشه>` عوض کنید.
- **هنوز ساخته نشده:**
  - به‌روزرسانی خودکار.
  - تب‌ها و چند پنجره (فاز ۱۳).
  - آیکون در system tray برای اینکه برنامه با بستن پنجره در پس‌زمینه باز بماند.
