# Chart Terminal

**یک ترمینال رایگان و متن‌باز برای نمودار و تحقیق معاملاتی: کریپتو، فارکس، سهام و بازار ایران.**
نمودار، ابزارهای رسم، اندیکاتور، اسکریپت‌های خودتان (Pine، MQL، NinjaScript و Python)، بک‌تست، هشدار، ژورنال معاملاتی، فید اجتماعی و رابط فارسی راست‌به‌چپ؛ همه در یک برنامه که روی ویندوز، لینوکس، اندروید و سرور شخصی شما اجرا می‌شود.

> Chart Terminal یک پروژه‌ی مستقل است که از صفر نوشته شده و به TradingView، MetaQuotes یا NinjaTrader وابسته نیست. نمودارها با کتابخانه‌ی متن‌باز `lightweight-charts` شرکت TradingView (Apache-2.0) کشیده می‌شوند.

## امکانات

**نمودار**
- ۱۸ نوع نمودار (کندل، Heikin-Ashi، Renko، Kagi، Point & Figure، Range، Line break، Baseline و بیشتر).
- ۹۲ ابزار رسم در ۷ گروه: خط روند، فیبوناچی، Gann، Pitchfork، کانال، الگوها، شکل‌ها، یادداشت، اندازه‌گیری و جعبه‌ی موقعیت. هر ابزار پنجره‌ی ویژگی، قالب، نوار شناور، Magnet و انتخاب چندتایی دارد.
- چیدمان تا ۱۶ نمودار با همگام‌سازی نماد، تایم‌فریم، crosshair و زمان؛ ذخیره، خروجی گرفتن و اشتراک چیدمان.
- مقایسه‌ی نمادها و ریاضی روی نمادها (`BTCUSDT/ETHUSDT`)، تایم‌فریم سفارشی از ثانیه تا ماه، Bar Replay، Undo/Redo، مقیاس لگاریتمی و درصدی.
- یک کادر جستجو برای همه‌چیز: `btcusdt` را بنویسید تا اسپات، پرپچوال (`.P`)، فیوچرز و نمادهای دامیننس همه‌ی صرافی‌های وصل‌شده را ببینید؛ یک صرافی را انتخاب کنید تا فقط از همان بیاید.

**اسکریپت‌های خودتان، بدون نصب نرم‌افزار اضافه**
- مفسر **Pine Script** (زیرمجموعه‌ی v5/v6) با ویرایشگر کد، تکمیل خودکار و کتابخانه‌ی اسکریپت‌های آماده.
- کامپایلر و اجراکننده‌ی **MQL4 / MQL5** (اکسپرت و اندیکاتور) بدون نصب MetaTrader.
- کامپایلر و اجراکننده‌ی **NinjaScript (C#)** (اندیکاتور و استراتژی) بدون نصب NinjaTrader.
- تب **Python** برای اجرای کد پایتون خودتان روی داده‌ی نمودار.
- اسکریپت‌ها با سقف تعداد حلقه، پنهان‌بودن globalهای مرورگر و فهرست ممنوعه‌ی نام‌های خطرناک اجرا می‌شوند؛ ولی در پردازه‌ی جدا اجرا نمی‌شوند، پس فقط اسکریپت‌های مورد اعتماد را اجرا کنید.

**بک‌تست**
- Strategy Tester با ۵۳ معیار، منحنی سرمایه در برابر Buy & Hold، فهرست معاملات و خروجی CSV.
- بهینه‌سازی، Walk-forward، Monte Carlo، بک‌تست پورتفولیو روی چند نماد و سازنده‌ی استراتژی بدون کد.
- Forward test: اجرای زنده‌ی استراتژی روی حساب تمرینی.

**بازارها و داده**
- ۱۰۳ صرافی کریپتو با CCXT (اسپات، پرپچوال، فیوچرز)، فارکس، فلزات، انرژی، شاخص‌ها و سهام.
- دیده‌بان، اسکرینر (حتی با نوشتن یک جمله)، نقشه‌ی حرارتی، پرنوسان‌ها، جفت‌های DEX، تقویم اقتصادی، اخبار، دامیننس کریپتو (`BTC.D`، `TOTAL`، `TOTAL2` ...).
- **بازار ایران:** نوبیتکس، tgju (دلار، طلا، سکه) و بورس تهران، با تقویم شمسی و رابط فارسی راست‌به‌چپ.
- Order flow و عمق Level 2، open interest، funding و لیکوئید شدن‌ها.

**معامله**
- معامله‌ی تمرینی با سفارش Market، Limit و Stop، حد سود/ضرر و برنامه‌ی خروج چندمرحله‌ای.
- حساب‌های **testnet** صرافی‌ها و پل MT5 دمو، از همان پنل سفارش.

**هشدار و اعلان**
- هشدار سمت سرور که با بسته بودن برنامه هم کار می‌کند.
- پنجره و صدا، Web Push، تلگرام، ایمیل و webhook.

**ژورنال، ریسک و کمک‌های تحلیلی**
- ژورنال معاملاتی با فضای کار کامل و ابزارهای ریسک (اندازه‌ی موقعیت و غیره).
- تحلیل خودکار نمودار و «مهارت‌های» معاملاتی که داخل برنامه و بدون هیچ سرویس هوش مصنوعی اجرا می‌شوند.
- اختیاری: مدل زبانی محلی و ابزارهای یادگیری ماشین با Python.

**جامعه (Community)** *(روی سرور عمومی)*
- اشتراک تحلیل با عکس نمودار، لایک، کامنت، دنبال‌کردن افراد و چت زنده (اتاق عمومی و یک اتاق برای هر نماد)، با گزارش، بلاک و مدیریت ادمین.

**حساب و همگام‌سازی**
- سرور خصوصی یک رمز دارد. روی سرور عمومی: حساب کاربری با ورود از **Google، Apple یا تلگرام**، کد دعوت، و همگام‌سازی تنظیمات، دیده‌بان و چیدمان بین دستگاه‌ها.

**برنامه برای هر دستگاه**
- نصبی ویندوز (x64 و ARM64)، لینوکس (AppImage، deb، pacman)، اندروید (APK و PWA)، نسخه‌ی سبک بدون Electron، Docker و سرور رزبری پای با یک دستور.
- گزارش خودکار باگ و کرش برای سازنده (بدون کلید، رمز و آدرس؛ قابل خاموش کردن).

## چه چیزی کار می‌کند و چه چیزی هنوز نه

- **معامله با پول واقعی فعال نیست.** فقط حساب تمرینی و testnet صرافی‌ها پشتیبانی می‌شود.
- **روی سرویس زنده امتحان نشده** (فقط ساخته و با تست واحد آزموده شده): منبع‌های ایرانی و پل MetaTrader 5.
- نصبی‌های ویندوز **امضای دیجیتال ندارند**؛ پس بار اول Windows SmartScreen هشدار می‌دهد.
- منبع‌های رایگان داده (مثل Yahoo برای فارکس و سهام) غیررسمی‌اند، ممکن است تأخیر داشته باشند و برای استفاده‌ی شخصی‌اند.
- فایل‌های کامپایل‌شده‌ی `.ex4` / `.ex5` و DLL اجرا نمی‌شوند؛ سورس برنامه‌های MQL لازم است.
- Binance و Bybit برخی کشورها (مثل ایران) را می‌بندند. سرور را خارج از ایران یا پشت VPN اجرا کنید.

## شروع کار

### الف. نصب برنامه (ساده‌ترین راه)

آخرین نسخه را از صفحه‌ی **[Releases](../../releases)** بگیرید.

| دستگاه | فایل | مراحل |
|---|---|---|
| **ویندوز** | `Chart Terminal Setup <نسخه>.exe` (x64 یا ARM64) | اجرایش کنید. اگر SmartScreen هشدار داد: *More info ← Run anyway*. بار اول برنامه از شما یک رمز می‌خواهد. |
| **اندروید** | `Chart-Terminal-<نسخه>-android.apk` | نصب از مرورگر یا مدیر فایل را مجاز کنید و APK را باز کنید. یک اپ واحد: تنهایی فقط Binance دارد؛ به سرور خودتان وصلش کنید (روی همان وای‌فای خودکار پیدا می‌شود، یا با QR جفت کنید) تا همه‌ی صرافی‌ها و بروکرها را داشته باشد. |
| **لینوکس** | `.AppImage`، `.deb` یا بسته‌ی pacman | `sudo apt install ./<فایل>.deb` یا `chmod +x <فایل>.AppImage` و اجرا. |
| **نسخه‌ی سبک (ویندوز/لینوکس)** | zip / tar.gz | باز کنید و `install.ps1` / `install.sh` را اجرا کنید؛ [docs/lite.md](docs/lite.md). |

برنامه داده‌هایش را روی کامپیوتر شما نگه می‌دارد (ویندوز: `%APPDATA%\Chart Terminal`). بستن پنجره سرور را در system tray روشن نگه می‌دارد تا هشدارها کار کنند. راهنمای کامل: [docs/desktop.md](docs/desktop.md)، [docs/android-apk.md](docs/android-apk.md).

### ب. سرور شخصی (خصوصی؛ رزبری پای، لینوکس، Docker)

سرور شخصی هشدار و اعلان را شبانه‌روز روشن نگه می‌دارد و گوشی و کامپیوترتان داده‌ی یکسانی دارند. نیاز: Docker (یا Node.js 24 به بالا) و یک کامپیوتر همیشه‌روشن در شبکه‌ی خانه.

**با Docker (هر لینوکس، رزبری پای ۴ یا ۵):**
```bash
git clone https://github.com/SepiNick/Chart-Terminal.git
cd Chart-Terminal
docker compose up -d --build
```
1. روی همان دستگاه `http://localhost:8787` را باز کنید و اولین رمز را بگذارید (فقط از خود دستگاه ممکن است).
2. از گوشی یا کامپیوتر دیگر با `https://<IP دستگاه>:8443` وصل شوید و یک بار گواهی را از `/ca.crt` نصب کنید (آیفون: `/ca.mobileconfig`).
3. برای هشدار در تلگرام: با `@BotFather` یک ربات بسازید، بعد در برنامه *Server & notifications ← Telegram* را باز کنید، توکن را بچسبانید و گفتگوی خودتان را انتخاب کنید.

**رزبری پای با یک دستور** (از کامپیوترتان): `scripts/deploy-pi.sh pi@<آدرس پای>`؛ [docs/raspberry-pi.md](docs/raspberry-pi.md). **بدون Docker یا روی لپ‌تاپ:** [docs/headless-server.md](docs/headless-server.md). **راه‌اندازی گوشی و گواهی:** [docs/lan-setup.md](docs/lan-setup.md)، [docs/android.md](docs/android.md).

### ج. سرور عمومی با حساب کاربری و جامعه

برای چند نفر: حساب کاربری، ورود با Google/Apple/تلگرام، و فید و چت Community.

```bash
DOMAIN=charts.example.com docker compose -f docker-compose.public.yml up -d --build
docker compose -f docker-compose.public.yml exec app node server/cli.ts invite 1 7 "دوست"
```
1. دامنه را به سرور وصل کنید و پورت‌های ۸۰ و ۴۴۳ را باز کنید؛ HTTPS خودکار برپا می‌شود.
2. رمز اول مدیر یک بار در لاگ چاپ می‌شود: `docker compose -f docker-compose.public.yml logs app`.
3. ثبت‌نام پیش‌فرض با کد دعوت است (`CT_REGISTRATION=invite`؛ همچنین `open` یا `closed`).
4. ورود اجتماعی را با متغیرهای محیطی روی سرور روشن کنید: Google و Apple ([docs/oauth-setup.md](docs/oauth-setup.md)) و تلگرام ([docs/telegram-login-setup.md](docs/telegram-login-setup.md)). بدون آن‌ها فقط ورود با رمز نشان داده می‌شود.
5. Community به چیز دیگری نیاز ندارد؛ [docs/community.md](docs/community.md).

راهنمای کامل: [docs/docker.md](docs/docker.md).

**اختیاری: دریافت گزارش باگ و کرش.** Worker کوچک Cloudflare در `bugreport-worker/` را منتشر کنید (حساب رایگان و یک ربات تلگرام): همان‌جا `npx wrangler login` و بعد `node setup.mjs` را بزنید و برنامه‌ها را با `VITE_BUG_REPORT_URL` برابر آدرس آن بسازید. جزئیات: [bugreport-worker/README.md](bugreport-worker/README.md).

### د. اجرا از سورس

نیاز: Node.js نسخه‌ی ۲۴ یا بالاتر.

```bash
npm install && npm --prefix server install
npm run server   # سرور داده روی 127.0.0.1:8787 (برای صرافی‌های دیگر، فارکس و بازار ایران لازم است)
npm run dev      # برنامه روی http://localhost:5173
npm test         # تست‌ها
npm run build    # بیلد نهایی
```
ساخت نصبی‌ها: ویندوز `cd desktop && npm run dist:win`، اندروید `cd android && ./gradlew assembleRelease`، نسخه‌ی سبک `npm run build:lite`. برای توسعه‌دهندگان: نقشه‌ی کد در [docs/development.md](docs/development.md).
